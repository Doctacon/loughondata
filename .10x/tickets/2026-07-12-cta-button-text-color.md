# Make primary CTA button text dark

## Scope

Change the visible text and arrow of every amber `Tell me what’s brittle` primary CTA button to the approved dark ink color (`#17201e`) in both appearances.

## Acceptance criteria

1. Primary amber email CTA text is dark ink, not cyan/light blue, in dark and light appearance.
2. The amber/dark pair retains accessible contrast.
3. No other link, navigation, or secondary-action color changes.
4. Hugo build and generated output validate successfully.

## Blockers

None. The user explicitly selected black/dark CTA text.
